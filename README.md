# Brocade AI - brocade motifs detection

## Dataset
CHINTEXDB-PERU28 is a dataset composed of 1358 images of traditional Andean hand-woven iconographies. This dataset includes 28 different types of iconographies. The 100 % of the images in the dataset were captured by the authors with a Huawei P Smart smartphone, HONOR Magic5 Lite and a Nikon Coolpix p520 professional camera under the supervision of textile center managers at Chinchero, Cusco, Peru.

![alt text](data/template/1171_Iconography.jpg)

# Problem
Mass-produced brocade make it difficult for local artisans to sell authentic handmade brocade. This project use AI with classification and object detection with image data to find unique motifs of some ethnic minority and distinguish them with factory imitations.

## Models
- Classfication: AlexNet model
- Object detection: YOLO model
